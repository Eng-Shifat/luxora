# Luxora – Image Guide

Image gulo `client/public/images/` er vitor niche dewa folder e rakho.
**File er nam hubohu nicher moto dite hobe.** Code e kichu likha lagbe na, save korlei site e chole ashbe.
Format: `.webp`, `.jpg`, `.jpeg`, `.png` (jeta khushi).

```
client/public/images/
├── hero/
│   └── hero.png
├── categories/
│   ├── summer.jpg
│   ├── accessories.jpg
│   ├── footwear.jpg
│   ├── sunglasses.jpg
│   └── outfits.jpg
└── products/
    ├── product-01.jpg  ... product-10.jpg
```
